# 🛒 Proyecto: Lo quieres, te lo vendo

¡Bienvenidos al repositorio de **Lo quieres, te lo vendo**! 🚀  
Este proyecto consiste en el sitio web de un emprendimiento de compras y ventas en línea. Aquí comparamos cómo se ve y funciona la página utilizando distintos frameworks de diseño y validaciones.

## 📁 Estructura de Carpetas

El proyecto está organizado en 3 carpetas principales para comparar los distintos enfoques:

1. **`proyecto-web/`**: Versión principal diseñada con **Bootstrap 5**.
2. **`proyecto-web - Materialize/`**: Mismo sitio web, pero adaptado con **Materialize CSS** (estilo Google).
3. **`proyecto-web-validaciones/`**: Versión enfocada en la **validación nativa de HTML5** para que los formularios verifiquen que los datos estén bien escritos antes de enviar.

---

## ⚔️ ¿Qué aprendimos al comparar los Frameworks?

### 🟦 Bootstrap 5
* **Lo bueno:** Es muy fácil de usar, la página se adapta rápido a celulares, tablets y computadores.
* **Aspecto:** Diseño moderno, limpio y profesional.

### 🟥 Materialize CSS
* **Lo bueno:** Tiene un estilo visual parecido a las aplicaciones de Google (con efectos de sombras y animaciones).
* **Detalle a considerar:** Requiere un par de líneas extra de JavaScript para hacer funcionar cosas como el menú hamburguesa en celulares.

### ✍️ Validaciones HTML5
* **¿Qué hace?:** Revisa automáticamente que el usuario no deje campos vacíos, que escriba un correo válido (`ejemplo@correo.com`) y que el mensaje tenga un largo mínimo. ¡Sin necesidad de instalar programas raros!

---

## 🛠️ ¿Cómo probar el proyecto?

1. Entra a cualquiera de las 3 carpetas principales.
2. Abre el archivo **`index.html`** o **`contacto.html`** haciendo doble clic sobre él (se abrirá en tu navegador web habitual).
3. En la página de **Contacto**, prueba enviar el formulario vacío para ver cómo funcionan los mensajes de aviso nativos.
